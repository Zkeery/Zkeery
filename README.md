### 关于我 / About

我是 Zkeery，一名有测试与后端开发背景的 AI 产品经理。测试经历让我重视质量与效果验证，后端开发经历让我理解技术边界与实现成本。

我关注真实场景中的 AI 应用：什么问题值得解决，AI 适合做到哪一步，以及怎样衡量效果。与技术团队一起，在用户体验、成本和质量之间做取舍，推动产品落地与迭代。
